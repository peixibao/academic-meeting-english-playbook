# Academic Meeting English Playbook

Reusable spoken English and realistic practice for prospective-supervisor meetings, thesis discussions and research-group meetings.

**Start here:** [Meeting map](guide/00-how-meetings-work.md) · [Learning method](guide/01-how-to-learn-and-update.md) · [Verified resources](guide/02-official-guides-and-videos.md)

## Principle: modular, not memorized

A meeting is a two-way conversation. Assemble an answer from a communication purpose (greet, clarify, connect research, ask, summarize) rather than learning a fixed speech. The order of topics may change.

**Reusable core:** language functions and meeting skills in the modules below.
**Professor-specific layer:** paper-specific notes and prospective projects in a private copy of [Professor brief](templates/professor-brief-template.md). Do not publish actual emails, invitation URLs, unpublished study details or private assessments.

## Conversation arc

1. Set up the call and greet.
2. Make a concise introduction; listen to the professor's opening.
3. Connect a specific paper/method to your own experience.
4. Explore feasible research / thesis questions together.
5. Ask about supervision, contributions, training and mutual expectations.
6. Recap next steps, close, and follow up appropriately.

## Update rules

Read the latest version before editing; preserve previous phrases unless wrong or obsolete; record important changes in CHANGELOG; create a descriptive Git commit. GitHub is updated only when someone initiates an editing session, not continuously in the background.

## Safety and sharing

This is a PUBLIC teaching repository. Avoid actual private correspondence, meeting links, restricted data and recordings. Keep sensitive meeting-specific notes locally or in another private repository. Example conversations are fictional. Sources are linked and summarized; original external educational materials are not copied in full.

## Scope

This repository offers general communication practice. It does not establish any individual university's admission, funding, supervision or authorship rules. Verify those separately.
