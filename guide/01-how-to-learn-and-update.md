# 01 · Learning method

## Train conversation functions, not a theatrical script

For each expression, store:
- Purpose: greet / transition / clarify / summarize / question / disagree / close
- Spoken example, plus two adaptable alternatives
- Formality: relaxed professional / more formal
- Situation and expected next turn
- Personal mastery: new / practicing / comfortable / automatic

## Four levels

1. **Survival:** enter the call, greet, ask someone to repeat, finish politely.
2. **Exchange:** 30- and 90-second introductions, one example of a project, relevant follow-up questions.
3. **Discussion:** evaluate an idea, uncertainty, trade-offs, feasibility and project roles.
4. **Independence:** respond to unexpected turns, diplomatically disagree, recap commitments.

## A ten-minute practice loop

1. 1 minute: listen to or read a native-like dialogue.
2. 2 minutes: shadow only 2–3 useful expressions.
3. 3 minutes: answer a new prompt without a script.
4. 2 minutes: receive sentence-by-sentence feedback.
5. 2 minutes: retry the answer and record what is transferable.

For user speech feedback, first explain original wording sentence by sentence, then usable substitutions, then an IELTS-safe polished version if useful, and a conversational spoken alternative. Preserve the intended scientific meaning.

Never invent experience, results, publications or promises. Distinguish factual research experience from hypothetical research interests.
